# DimensionTres

Tienda online de **DimensionTres**: hardware, gaming y servicio técnico en Villa María, Córdoba.

**Sitio web:** https://dimensiontres.com

## Qué ofrece el sitio

- Catálogo de consolas, juegos, PC y componentes, notebooks, periféricos y accesorios.
- Buscador con sugerencias, filtros por categoría, marca, precio y disponibilidad.
- Ficha de producto con precio, cuotas de Mercado Pago y opciones de retiro en el local.
- Carrito y pago con Mercado Pago o transferencia.
- Cuenta de cliente con historial de compras y reparaciones.
- Información de servicio técnico, horarios y ubicación.

## Tecnologías

- HTML, CSS y JavaScript, con Tailwind CSS compilado.
- [Supabase](https://supabase.com) para el catálogo, las cuentas y los pedidos.
- Pagos con Mercado Pago.

## Estructura

| Carpeta o archivo | Contenido |
|---|---|
| `index.html`, `catalogo.html`, `producto.html`, `carrito.html`, `cuenta.html` | Páginas del sitio |
| `*.css`, `*.js` | Estilos y lógica de cada página |
| `img/` | Imágenes del sitio y de los productos |
| `fonts/` | Tipografías locales |
